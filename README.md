# HERday To-Do App

HERday is a daily to-do/checklist app for the busy, goal-oriented woman that needs a simple, visual way to organize her tasks and track progress. Helping the user become HER one task at a time.

## Features

- Add tasks to the checklist
- Mark tasks as complete
- Filter the list to show all tasks or only remaining tasks
- Remove completed tasks
- View completion progress
- See a message when all tasks are complete

## Run the App

Open `TODOapp.html` in a web browser. The app uses `TODO.js` for its interactions and `TODOstyles.css` for styling.

## Note

Tasks are stored in memory, so changes reset when the page is refreshed.
